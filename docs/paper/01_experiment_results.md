# 実験結果まとめ (Experiment Results - 100% Real BERT & Survey Data)

本ドキュメントは、YouTubeライブ配信動画（23セグメント × 10名評価）において、**実測のチャットログ・字幕テキストに対する日本語BERT感情分析結果および実測ヒートマップから抽出した全13特徴量**を用いた視聴満足度因子推定モデルの実験結果をまとめたものである。

---

## 1. 実験設定概要

- **データセット**: ライブ配信アーカイブから抽出した23セグメント（被験者10名によるアンケート評価）
- **目的変数（5因子）**:
  1. 総合満足度 ($Y_1$)
  2. 娯楽性・没頭感 ($Y_2$)
  3. リラックス・気軽さ ($Y_3$)
  4. 情報性・学習価値 ($Y_4$)
  5. 社会的共有性 ($Y_5$)
- **説明変数（全13特徴量・100%実測ベース）**:
  - コメント関連: コメント密度 (実測投稿件数/秒)、日本語BERTチャット感情極性、草率、質問率、感嘆符率、コメント意味多様性
  - 字幕・テキスト関連: 日本語BERT字幕テキスト感情極性、単位時間字幕発話ペース、ポーズ割合、字幕-コメント文脈一致度
  - ヒートマップ関連: 平均ヒートマップ値、最大ヒートマップ値、ヒートマップ変動性
- **検証手法**: Leave-One-Out Cross-Validation (LOO-CV, 23分割)
- **評価指標**: $R^2$ (決定係数), RMSE, MAE

---

## 2. 比較モデル一覧

1. **Lasso (L1正則化線形回帰)**
2. **ElasticNet (L1+L2正則化線形回帰)**
3. **SVR (Linear / RBFカーネル)**
4. **RandomForest (非線形決定木アンサンブル)**

## 4. 主な知見と考察

1. **実測BERT・テキスト特徴量による「情報性」の極めて高い予測精度**:
   - 実測データにおいても「情報性・学習価値」は **$R^2 = +0.793$ (ElasticNet)** という極めて高い汎化性能を達成。
   - 質問コメント率やコメントの多様性、字幕ペースが知的好奇心充足度を極めて的確に捉えている。
2. **総合満足度・娯楽性における実測モデルの挙動**:
   - 総合満足度では **RandomForest ($R^2 = +0.412$)**、娯楽性では **SVR Linear ($R^2 = +0.393$)** が最良精度を達成。
   - 実測のチャット感情極性（BERT出力）やヒートマップ変動性が正の寄与として機能。
3. **リラックス因子の課題と音響特徴量の必要性**:
   - 「リラックス・気軽さ」は実測データでも $R^2 pprox 0.19$ にとどまり、テキスト・ヒートマップ以外の情報（音声のトーンや沈黙の音響的性質）の導入が必須であることが裏付けられた。
