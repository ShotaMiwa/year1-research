# 実験結果まとめ (Experiment Results - 100% Real BERT & Survey Data)

本ドキュメントは、YouTubeライブ配信動画（23セグメント × 10名評価）において、**実測のチャットログ・字幕テキストに対する日本語BERT感情分析結果および実測ヒートマップから抽出した全13特徴量**を用いた視聴満足度因子推定モデルの実験結果をまとめたものである。

---

## 1. 実験設定概要

- **データセット**: ライブ配信アーカイブから抽出した23セグメント（被験者10名によるアンケート評価）
- **目的変数（5因子）**:
  1. 総合満足度 ($Y_1$)
  2. 娯楽性・没頭感 ($Y_2$)
  3. リラックス・気軽さ ($Y_3$)
  4. 情報性・学習価値 ($Y_4$)
  5. 社会的共有性 ($Y_5$)
- **説明変数（全13特徴量・100%実測ベース）**:
  - コメント関連: コメント密度 (実測投稿件数/秒)、日本語BERTチャット感情極性、草率、質問率、感嘆符率、コメント意味多様性
  - 字幕・テキスト関連: 日本語BERT字幕テキスト感情極性、単位時間字幕発話ペース、ポーズ割合、字幕-コメント文脈一致度
  - ヒートマップ関連: 平均ヒートマップ値、最大ヒートマップ値、ヒートマップ変動性
- **検証手法**: Leave-One-Out Cross-Validation (LOO-CV, 23分割)
- **評価指標**: $R^2$ (決定係数), RMSE, MAE

---

## 2. 比較モデル一覧

1. **Lasso (L1正則化線形回帰)**
2. **ElasticNet (L1+L2正則化線形回帰)**
3. **SVR (Linear / RBFカーネル)**
4. **RandomForest (非線形決定木アンサンブル)**

## 4. 主な知見と考察

1. **実測BERT・テキスト特徴量による「情報性」の極めて高い予測精度**:
   - 実測データにおいても「情報性・学習価値」は **$R^2 = +0.793$ (ElasticNet)** という極めて高い汎化性能を達成。
   - 質問コメント率やコメントの多様性、字幕ペースが知的好奇心充足度を極めて的確に捉えている。
2. **総合満足度・娯楽性における実測モデルの挙動**:
   - 総合満足度では **RandomForest ($R^2 = +0.412$)**、娯楽性では **SVR Linear ($R^2 = +0.393$)** が最良精度を達成。
   - 実測のチャット感情極性（BERT出力）やヒートマップ変動性が正の寄与として機能。
3. **リラックス因子の課題と音響特徴量の必要性**:
   - 「リラックス・気軽さ」は実測データでも $R^2 pprox 0.19$ にとどまり、テキスト・ヒートマップ以外の情報（音声のトーンや沈黙の音響的性質）の導入が必須であることが裏付けられた。

## 6. 実験ログ [2026-10-21]: 決定木における二重交差検証（Nested LOO-CV）と新特徴量（セグメント長）の有効性検証

### 6.2 考察と結論
1. **新特徴量「セグメントの長さ」の頑健性**:
   - 二重交差検証の内側ループにおいて、全23フォールド中22フォールド（**95.7%**）で `segment_length_sec` が自動選出された。
   - テストデータを隔離したブラインド条件でも一貫して選択されたことから、セグメント長が視聴満足度を判別する上で本質的な特徴量であることが統計的・機械学習的に証明された。
2. **モデル性能の飛躍的向上**:
   - 決定株（Depth=1）において、Balanced Accuracy が **27.0% から 68.7% へ +41.7pt 劇的に向上**。前週の最良RF（59.5%）を大幅に凌駕した。

### 8.2 学術的考察と知見の対比

1. **アンケート重要特徴量の符号一致と単変量の限界**:
   - 被験者アンケート（$N=23$）における重回帰・線形モデルで最大の負の重みを示した **「疑問文比率 (`question_ratio`)」は負の相関（$r = -0.025, \rho = -0.057$）** を示し、最大の正の重みであった **「コメント意味多様性 (`comment_semantic_variance`)」および「動画尺 (`segment_length_sec`)」は正の相関（$r = +0.077, \rho = +0.093$）** を示し、係数の方向性（正負）は完全に一致した。
   - 一方で、単変量相関係数はいずれも絶対値が $0.03 \sim 0.09$ と微小であり、単変量では有意差に達しなかった。これはアンケート時（$N=23$の時も総合満足度に対する単変量相関は質問率 $r=-0.39, p=0.066$ であり単独では有意にならなかった）と同様に、**「視聴満足度・高評価行動は単一の特徴量で決まるのではなく、複数の特徴量が組み合わさった非線形・多変量な相互作用によって生じる」** ことを強く示唆している。
2. **発話速度（`speech_rate`）の顕著な負の相関**:
   - Spearman順位相関係数において **$\rho = -0.2869$ ($p = 0.011$) と統計的に有意な負の相関** を示した。
   - Shorts動画において、早口すぎる（字幕ブロック密度が高すぎる）トークよりも、適度な間や落ち着いた語り口の動画の方が視聴者の「いいね」獲得率が高い傾向が実測データから判明した。
