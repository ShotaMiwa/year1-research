## 3. LMM分析から得られた総括的考察

1. **総合満足度は個人差を考慮しても単一特徴量では有意にならない**
   13種類すべての特徴量において  > 0.05$ であり、=23$ の時と同様に単独での線形予測は困難であることが再確認された。満足度は個別因子の複合によって形成されるため、機械学習等による非線形統合が不可欠であるエビデンスとなる。

2. **検出力向上による重要特徴量の新規有意化（6件）**
   - **字幕-コメント類似度 $\rightarrow$ 情報性** ($\beta = +0.137, p = 0.020$): 話題の一致が学習価値を高める。
   - **無音割合 $\rightarrow$ 娯楽性・没頭感** ($\beta = +0.116, p = 0.029$) / **リラックス** ($\beta = +0.110, p = 0.035$): 適切なポーズ（間）の重要性。
   - **発話速度 $\rightarrow$ リラックス** ($\beta = -0.108, p = 0.038$): 早口区間における気疲れ。
   - **コメント意味多様性 $\rightarrow$ 娯楽性** ($\beta = -0.134, p = 0.012$) / **リラックス** ($\beta = -0.136, p = 0.009$): 単一のノリ（一体感）が没頭感を高める。

3. **情報性における「盛り上がりとの背反」の強固な再現性**
   ヒートマップ値（平均・最大）および草・笑い率、字幕BERT感情極性の負の寄与は、 < 0.001$ という極めて高い統計的信頼性をもって維持された。
