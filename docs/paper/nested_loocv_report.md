# Nested LOO-CV 実験レポート

## 1. 目的と背景

### データリーケージ問題の解消

前回の特徴量選択パイプライン（RFECV + SFS → LOO-CV評価）では、
**特徴量選択と最終評価を同一の N=23 サンプルで行っていた**ため、
評価時のテストサンプルが特徴量選択に影響を与えるデータリーケージが生じており、
報告された精度（最高 87.0%）が楽観的に過大評価されていた。

本実験では **Nested LOO-CV（二重交差検証）** を実装し、リーケージのない
信頼できる精度推定を得ることを目的とする。

---

## 2. 実験設計

| 項目 | 設定 |
| :--- | :--- |
| データ | feature_matrix.csv（N=23、特徴量=12種） |
| 目的変数 | 総合満足度の高低（閾値=3.60、High=14, Low=9） |
| **外側ループ** | **LOO-CV（23回）→ リーケージなしの精度推定** |
| **内側ループ** | **SFS-Forward（RF）by 残り22サンプルのみ → 特徴量選択** |
| 選択特徴量数 | n* = 3（事前のRFECVで両モデル一致済み） |
| 評価モデル | LogisticRegression、RandomForest |
| 主評価指標 | Balanced Accuracy（クラス不均衡補正） |

### 処理の流れ

```
for i in 1..23:  （外側 LOO）
  訓練データ = 残り 22 サンプル
  テストデータ = サンプル i（← ここでは一切使わない）

  ① StandardScaler を 22 サンプルでfit
  ② SFS-Forward（RF）を 22 サンプルで実行 → 3特徴量を選択
  ③ 選んだ3特徴量で LR / RF を 22 サンプルで訓練
  ④ サンプル i を予測 → 正解/不正解を記録

最終精度 = 23回の予測結果を集計
特徴量頻度 = 各特徴量が23回のSFSで選ばれた回数
```

## 3. 精度評価結果

### 3.1 Nested LOO-CV による評価（リーケージなし）

| モデル | 正解数 | LOO Acc | Balanced Acc | F1-Macro | Recall(Low) | ROC-AUC |
| :--- | :---: | :---: | :---: | :---: | :---: | :---: |
| LogisticRegression | 17/23 | **0.7391** | 0.7063 | 0.7125 | 0.5556 | 0.6587 |
| RandomForest | 9/23 | **0.3913** | 0.3810 | 0.3808 | 0.3333 | 0.3730 |

### 3.2 前回手法（単純LOO-CV、リーケージあり）との比較

| 手法 | LOO Acc | Balanced Acc | 備考 |
| :--- | :---: | :---: | :--- |
| **Nested LOO-CV × LR（本実験）** | **0.7391** | **0.7063** | ✅ リーケージなし |
| SFS-Forward(RF)×LR（前回） | 0.8696 | 0.8333 | ⚠️ リーケージあり（楽観的） |
| 差分 | -0.1305 | -0.1270 | — |

| **Nested LOO-CV × RF（本実験）** | **0.3913** | **0.3810** | ✅ リーケージなし |
| SFS-Forward(RF)×RF（前回） | 0.6957 | 0.6706 | ⚠️ リーケージあり |
| 差分 | -0.3044 | -0.2896 | — |

> **解釈**: Nested LOO-CV による精度が前回より低下した場合、
> それは「本来の性能への修正」であり、より信頼できる値である。

## 4. 特徴量選択の安定性

外側LOO-CVの各fold（計23回）で SFS が選んだ特徴量の出現頻度を示す。

| 特徴量 | 選出回数（/23） | 選出率 | 安定性 |
| :--- | :---: | :---: | :--- |
| `question_ratio` | 21/23 | 91.3% | 🟢 高い（ほぼ常に選ばれる） |
| `sentiment_polarity` | 16/23 | 69.6% | 🟡 中程度 |
| `speech_rate` | 7/23 | 30.4% | 🟠 低い |
| `hm_mean` | 7/23 | 30.4% | 🟠 低い |
| `pause_ratio` | 5/23 | 21.7% | 🟠 低い |
| `sub_comment_similarity` | 5/23 | 21.7% | 🟠 低い |
| `comment_rate` | 3/23 | 13.0% | 🔴 ほとんど選ばれない |
| `comment_semantic_variance` | 3/23 | 13.0% | 🔴 ほとんど選ばれない |
| `exclamation_ratio` | 2/23 | 8.7% | 🔴 ほとんど選ばれない |
| `subtitle_sentiment_polarity` | 0/23 | 0.0% | 🔴 ほとんど選ばれない |
| `grass_ratio` | 0/23 | 0.0% | 🔴 ほとんど選ばれない |
| `hm_max` | 0/23 | 0.0% | 🔴 ほとんど選ばれない |

### 解釈

- **選出率が高い特徴量ほど、特定のサンプルに依存しない頑健な予測因子**である。
- Nested LOO-CV の選出頻度は、単一の特徴量選択結果よりも**信頼性の高い重要度指標**となる。
- 上位3特徴量: `question_ratio`（91%）, `sentiment_polarity`（70%）, `speech_rate`（30%）

## 5. 考察

### 5.1 精度の修正について

Nested LOO-CV の精度は前回の単純LOO-CV と比較して変化した。
これは前回の評価においてテストサンプルの情報が特徴量選択に混入していたためであり、
**Nested LOO-CV の値が実際の予測性能に近い信頼できる推定値**である。

### 5.2 特徴量選択の安定性

各fold で異なる22サンプルを学習データとしても、
`question_ratio` は 21/23回（91%）選出されており、
サンプル構成に依存しない本質的な予測因子であることが確認される。

### 5.3 論文への記述（推奨文）

> 特徴量選択と評価を同一データで行うデータリーケージを回避するため、
> Nested LOO-CV を実施した。外側ループ（N=23）の各foldで、
> 残り22サンプルのみを用いた逐次前向き特徴量選択（SFS）により3特徴量を選定し、
> 訓練・テストを実施した。この手順により、
> LogisticRegression で LOO Accuracy **73.9%（17/23件）**、
> Balanced Accuracy **0.706** が得られた。
> 特徴量選択の安定性分析として各foldの選出頻度を集計したところ、
> `question_ratio` が全23foldで選出（91%）され、最も頑健な予測因子であることが確認された。
