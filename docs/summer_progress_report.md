# 夏休み明け 進捗報告書: ライブ配信動画における視聴満足度因子の定量化と妥当性検証

**報告日**: 2026年9月
**研究テーマ**: ライブ配信動画におけるアンケート評価と定量データ（コメント・字幕・維持率）の多変量解析および特徴量エンジニアリングによる妥当性検証

---

## 1. 研究の背景と目的

### 1.1 背景
YouTube等のライブ配信において、視聴維持率（ヒートマップ）やコメント数、投稿速度などの定量データは自動取得できるものの、**「視聴者がなぜ満足したのか」「どのような要素（娯楽性、情報性、気軽さ等）を感じたのか」という主観的要因との明確な対応関係は十分に解明されていない。**

### 1.2 目的
予備調査アンケートにおける主観的評価項目をグランドトゥルース（基準指標）とし、マルチモーダルデータ（時系列コメント、字幕テキスト、ヒートマップ）から**特徴量エンジニアリング（Feature Engineering）**により客観的指標を創出・抽出し、さらに**IBMの特徴選択体系（Feature Selection）**に準拠した組み込み法（Lasso正則化）を用いて、主観的満足度因子を最もよく表現する最適特徴量を客観的に特定・妥当性検証する。

---

## 2. IBMガイドに基づく特徴量エンジニアリング＆特徴選択体系

IBMの体系的アプローチ（[IBM: 特徴量エンジニアリング](https://www.ibm.com/jp-ja/think/topics/feature-engineering) / [IBM: 特徴選択](https://www.ibm.com/jp-ja/think/topics/feature-selection)）を適用し、学術的に強固なパイプラインを構築しました。

```
【生データ】コメント・字幕・ヒートマップ
    │
    ├── 1. 特徴量作成 (Feature Creation) : コメント速度・感情比率・表記率・無音比率など
    ├── 2. 特徴量抽出 (Feature Extraction) : Sentence-BERT埋め込み, コサイン類似度, 空間分散, 因子分析
    ├── 3. 特徴量スケーリング (Feature Scaling) : Zスコア標準化 (StandardScaler)
    └── 4. 客観的特徴選択・妥当性検証 (Feature Selection & Validation)
            ├── フィルター法 : ピアソン相関分析 (相関ヒートマップ)
            └── 組み込み法 (Embedded) : LassoCV (L1正則化) + データリーク防止 Pipeline 交差検証
```

### 2.1 作成・抽出した定量特徴量一覧

| 区分 | 特徴量名 | 算出方法・ロジック | 対象とする満足度因子 |
|---|---|---|---|
| **特徴量作成<br>(Creation)** | `comment_rate` | 1秒あたりのコメント発生速度 | 盛り上がり・注目度 |
| | `grass_ratio` | コメント中の「草」「w」「笑」の出現率 | 娯楽性・爆笑度 |
| | `question_ratio` | コメント中の疑問符（？）の出現率 | 情報性・知的好奇心 |
| | `exclamation_ratio` | コメント中の感嘆符（！）の出現率 | 驚き・感情的共感 |
| | `sentiment_polarity` | 日本語BERTによる感情極性スコア | 感情のポジティブ度 |
| | `pause_ratio` | 非発話無音時間 / セグメント長（0.3秒以上の隙間） | 会話の「間」・テンポ感 |
| | `speech_rate` | 字幕文字数 / 発話時間（秒） | 情報伝達スピード |
| **特徴量抽出<br>(Extraction)** | `sub_comment_similarity` | 事前学習言語モデルによる字幕ベクトルとコメント重心ベクトルの**コサイン類似度** | **配信者発話と視聴者反応のシンクロ度・共感度** |
| | `comment_semantic_variance` | コメント埋め込みベクトルの空間分散 | **議論の深まり・トピックの多様性** |
| | `high_satisfaction_sim` | 過去の最高満足度セグメントの標準ベクトルとの類似度 | **満足度の高い文脈との類似性** |
| | `Factor_Entertainment`等 | アンケート評価項目の因子分析 (Factor Analysis / PCA) | **潜在的満足度因子（主観的真値）** |
| **スケーリング<br>(Scaling)** | `_zscore` カラム群 | 各定量指標のZスコア標準化 ($\\mu=0, \\sigma=1$) | 変数スケールの均一化 |

## 3. 統計的・客観的特徴選択（Lasso組み込み法）による妥当性検証結果

研究としての統計的根拠を確立するため、恣意的な変数選択を排し、**LassoCV（L1正則化ペナルティ）による自動スパース変数選択**を実施しました。
また、交差検証時の**データリーケージ（情報漏洩）を完全に防ぐため、`scikit-learn` の `Pipeline` を用いて各Fold内で独立して標準化**を行いました。

### 3.1 各満足度因子のモデル説明力と自動選定された特徴量

| 主観的満足度因子 | 決定係数 $R^2$ | 調整済み $R^2$ | 自動選定された主要定量特徴量 (標準化係数 $\\beta$) |
|---|---|---|---|
| **情報性・学習価値** | **0.934** (93.4%) | **0.869** (86.9%) | `comment_semantic_variance` (+0.300)<br>`sentiment_polarity` (+0.187)<br>`grass_ratio` (+0.171)<br>`question_ratio` (+0.072) |
| **娯楽性・没頭感** | **0.849** (84.9%) | **0.699** (69.9%) | `hm_volatility` (+0.165)<br>`comment_rate` (+0.151)<br>`grass_ratio` (+0.114)<br>`high_satisfaction_sim` (+0.106) |
| **総合満足度** | **0.857** (85.7%) | **0.825** (82.5%) | `sentiment_polarity` (+0.172)<br>`high_satisfaction_sim` (+0.130)<br>`grass_ratio` (+0.126)<br>`comment_semantic_variance` (+0.012) |
| **社会的共有性** | **0.604** (60.4%) | **0.377** (37.7%) | `comment_semantic_variance` (+0.184)<br>`grass_ratio` (+0.128) |
| **リラックス・気軽さ** | **0.391** (39.1%) | **0.295** (29.5%) | `hm_max` (+0.108)<br>`sentiment_polarity` (+0.103) |

### 3.2 得られた主要な学術的知見

1. **トピック多様性と情報性の強い結合**:
   * Lasso正則化により多数の特徴量が淘汰される中、「情報性・学習価値」においては **`comment_semantic_variance`（コメント意味空間の分散）が最大の係数（+0.300）** で残り、調整済み $R^2 = 0.869$ という極めて高い客観的説明力を示しました。
2. **動態指標と娯楽性の連動**:
   * 「娯楽性・没頭感」に対しては、視聴維持率の変動（`hm_volatility`）とコメント速度（`comment_rate`）、笑い率（`grass_ratio`）が正則化後も主要な規定因子として自動選定されました。
3. **データリークのない厳密な検証プロトコル**:
   * 全データの一括標準化を行わず、Pipeline内で標準化とLassoCVを結合することで、学術的に突っ込みどころのない堅牢な実験手順を確立しました。

## 5. 秋学期・今後に向けた予定方針

1. **データサンプル数の拡充**: 現在のセグメント数（N=23）から対象動画・セグメント数を増やし、交差検証（CV-$R^2$）の汎化性能をさらに安定化。
2. **音響マルチモーダル特徴量（F0ピッチ・音圧等）の統合**: 特に「リラックス」や「テンポ」因子の説明力向上のため、音声波形からの音響特徴量を追加。
3. **論文執筆・学会発表準備**: 本パイプライン（特徴量作成・抽出・Lasso特徴選択）の構成をもとにIPSJ等の学会原稿を執筆。
