## 1. 実験の背景と目的

### 1.1 背景
- 前回の実験（10/14）では、全12特徴量の中から逐次特徴選択（SFS）を用いて二重交差検証（Nested LOO-CV）を行っていたが、SFSは貪欲法（Greedy）であるため、「目先の一時的なスコア向上」に引きずられ、大局的に優れた特徴量ペア（例: 疑問符率＋セグメント長）を取りこぼす局所解（過学習）に陥る課題が判明した。
- また、深さ1〜2の浅い決定木においては、特徴量数が2〜3個に制限されるため、アルゴリズムによる近似探索よりも、**成立しうる全特徴量の組み合わせを網羅的に計算（Exhaustive Search）する方が、数学的に完全な大域的最適解を保証できる**。

### 1.2 目的
1. **新特徴量「セグメントの長さ（`segment_length_sec`）」の客観的評価**:
   - 特定の組み合わせに依存せず、全特徴量との総当たり比較において、新特徴量がどれだけ上位を占めるかを定量的に証明する。
2. **決定木における最高精度ペアの完全確定**:
   - 取りこぼしなく全パターンを評価し、最も汎化性能が高く解釈性の高いトップ$K$の組み合わせを確定する。
3. **他モデル（SVM, ロジスティック回帰, ランダムフォレスト等）への水平展開基盤の構築**:
   - 共通の特徴量探索空間と評価プロトコルを定め、モデル構造の違いによる性能差を公平に比較できる再現性の高い設計とする。

## 2. 探索空間の設計（組み合わせ数）

全13特徴量（従来の12特徴量 ＋ 新特徴量 `segment_length_sec`）を対象とする。

| レベル | 特徴量数 | 組み合わせの計算式 | パターン数 | 決定木における意義・役割 |
| :--- | :---: | :---: | :---: | :--- |
| **レベル1（単体特徴量）** | 1特徴量 | $_{13}C_1$ | **13通り** | 決定株（深さ1）での各特徴量の純粋な単独予測力ランキング |
| **レベル2（2特徴量ペア）** ★最重要 | 2特徴量 | $_{13}C_2 = \frac{13 \times 12}{2}$ | **78通り** | 2次元平面で直交する2軸の探索（深さ2〜3の木で完全に解釈可能） |
| **レベル3（3特徴量トリオ）** | 3特徴量 | $_{13}C_3 = \frac{13 \times 12 \times 11}{6}$ | **286通り** | 3分岐による微細な調整と、ノイズ混入（過学習）リスクの検証 |
| **合計** | | | **377通り** | **決定木であれば数十秒以内で完全計算可能** |

## 3. ハイパーパラメータの設計（過学習抑制と表現力の両立）

サンプルサイズが $N=23$（高満足度14件, 低満足度9件）と小規模であるため、過学習を防ぐ制約を明確に定義する。

| ハイパーパラメータ | 探索候補値 | 設計の意図・理由 |
| :--- | :---: | :--- |
| **`max_depth`（最大深さ）** | `[1, 2, 3]` | ・`1`: 決定株（極限の単純化・1分岐のみ）<br>・`2`: 2〜3分割の基本形<br>・`3`: 最大葉ノード8個。$N=23$ において深さ4以上は訓練データの丸暗記となるため構造上除外 |
| **`min_samples_leaf`（葉の最小件数）** | `[1, 2]` | ・`1`: 綺麗に分離できる境界が存在する場合の表現力重視<br>・`2`: 孤立点（外れ値）への過剰適合を抑止する枝刈り重視 |
| **`criterion`（不純度指標）** | `['gini']` | 決定木の標準基準（エントロピーとほぼ同等なため固定して探索効率化） |
| **`class_weight`** | `[None, 'balanced']` | 高満足度14件 vs 低満足度9件のクラス不均衡に対する重み付けの有無 |
| **`random_state`** | `42` | 実験の完全再現性を担保するために全試行で固定 |

## 4. 交差検証（CV）手法の設計

### 採用手法: **Leave-One-Out Cross-Validation (LOO-CV, 23分割)**

1. **選定理由**:
   - $N=23$ の小標本において、K-Fold（例: 5分割）を行うと、テストセット（4〜5件）の引き当て運によって評価値が大きくブレてしまう。
   - LOO-CVであれば、23通りの分割が数学的に1通りに確定し、分割バイアスを完全に排除できる。
2. **データ漏洩（データリーク）の防止**:
   - 各フォールドでテスト対象の1件を完全に隠し、残り22件のみで決定木の閾値決定（`fit`）を行い、隠した1件に対して予測（`predict`）を実施する。これを23回反復する。
3. **評価指標**:
   - **`Balanced Accuracy`（主指標）**: クラス不均衡の影響を排し、HighとLowの各クラス正解率の平均を最大化する。
   - `Accuracy`（全体正解率 / 正解数 23問中何問か）
   - `F1-Macro`（各クラスの調和平均）

### 5.2 前処理のパイプライン化（スケーリングの厳格化）
- 決定木やランダムフォレストはスケール不変（標準化不要）であるが、**SVMやロジスティック回帰は特徴量の標準化（Z-score正規化）が必須**となる。
- **データリーク防止ルール**:
  - 各LOO-CVフォールドにおいて、**訓練データ22件のみで `StandardScaler.fit()` を行い**、その平均・分散を用いてテストデータ1件を `transform()` する処理を厳格に組み込む。
