# 進捗報告：ダブルクロスバリデーションによる満足度分類とモデル比較（決定木 vs Random Forest）
**日付**: 2026年10月21日  
**報告者**: 三輪 昇汰  
**対象データ**: ライブ配信アーカイブ動画（23セグメント）  

---

## スライド1：研究目的

### 背景と目的
- **背景**: ライブ配信における視聴者満足度を高精度に推定し、どの配信特徴量（コメント・音響・セグメント構造等）が寄与しているかの意思決定ルールを解明することを目指している。
- **本報告の目的**:
  1. **厳密な汎化性能の把握（ダブルクロスバリデーション / Nested LOO-CV）**:
     - モデル選定や特徴量探索の過程でテストデータが漏洩する「楽観的バイアス」を完全に排除し、未見セグメントに対する真の分類性能を測定する。
  2. **決定木（Decision Tree）とランダムフォレスト（Random Forest）の公平な比較**:
     - 両モデルに対して**「同一の特徴量探索空間（377通り網羅探索）」**および**「同一のダブルCV評価プロトコル」**を適用し、単木とアンサンブルモデルにおける性能差および特徴量選定の安定性を明らかにする。

---

## スライド2：実験方法・検証プロトコル

### 1. データセットと抽出特徴量
- **サンプル数**: $N = 23$ セグメント（中央値 $3.60$ を境界として 高満足度 $14$ 件 / 低満足度 $9$ 件 に二値分類）
- **特徴量候補（全13種類）**:
  - **コメント系（5種）**: コメント密度 (`comment_rate`), 疑問符率 (`question_ratio`), 感嘆符率 (`exclamation_ratio`), コメント感情極性 (`sentiment_polarity`), 草コメント率 (`grass_ratio`)
  - **動画・音響系（2種）**: 発話速度 (`speech_rate`), 無音割合 (`pause_ratio`)
  - **視線ヒートマップ系（2種）**: 視線集中度平均 (`hm_mean`), 視線集中度最大値 (`hm_max`)
  - **マルチモーダル・言語系（3種）**: 字幕感情極性 (`subtitle_sentiment_polarity`), コメント分散 (`comment_semantic_variance`), 字幕-コメント類似度 (`sub_comment_similarity`)
  - **配信構造系（新特徴量 1種）**: セグメント時間長 (`segment_length_sec`)

### 2. ダブルクロスバリデーション（Double CV / Nested LOO-CV）の設計
モデル選定（特徴量・ハイパーパラメータ探索）とモデル評価を2重の交差検証ループに完全分離。
- **外側ループ（Outer LOO-CV, 23分割）**:
  - テストデータ1件を完全に隔離。残る22件のみを内側ループに渡す。
- **内側ループ（Inner LOO-CV, 22分割）**:
  - 22件の訓練データ内部で「1〜3個の特徴量組み合わせ（377通り）」を網羅探索。
  - 内側LOO-CVの `Balanced Accuracy` が最高となったモデル設定・特徴量セットを選出。
- **外側テスト評価**:
  - 選定された最良設定で22件を学習し、隔離していたテスト1件を予測。これを23回繰り返し、外側予測の集計から真の汎化性能を算出。

## スライド3：分類性能（最重要）

### 決定木 vs Random Forest の真の汎化性能（外側LOO-CV結果）
主指標として不均衡データに頑健な **Balanced Accuracy** を採用し、Accuracy・Macro F1・混同行列を併記。

| 評価モデル | 正解数 / 全件 | Accuracy | Balanced Accuracy (主指標) | Macro F1 | 内側LOO-CV平均 (モデル選定時) |
| :--- | :---: | :---: | :---: | :---: | :---: |
| **決定木 (Decision Tree)** | **13 / 23** | **56.5%** | **54.4%** | **54.4%** | 85.8% |
| **ランダムフォレスト (Random Forest)** | 12 / 23 | 52.2% | 46.8% | 45.6% | 78.7% |
| *(参考) チャンスレベル* | - | 50.0% | 50.0% | - | - |

### 混同行列（Confusion Matrix）

#### ① 決定木（Decision Tree）
- **低満足度（True: Low 9件）**: 正解 4件, 誤分類（Highと予測）5件 [再現率: 44.4%]
- **高満足度（True: High 14件）**: 正解 9件, 誤分類（Lowと予測）5件 [再現率: 64.3%]
- $\rightarrow$ **Balanced Accuracy = (44.4% + 64.3%) / 2 = 54.4%**

#### ② ランダムフォレスト（Random Forest）
- **低満足度（True: Low 9件）**: 正解 2件, 誤分類（Highと予測）7件 [再現率: 22.2%]
- **高満足度（True: High 14件）**: 正解 10件, 誤分類（Lowと予測）4件 [再現率: 71.4%]
- $\rightarrow$ **Balanced Accuracy = (22.2% + 71.4%) / 2 = 46.8%**

> **【重要な知見（楽観的バイアスの排除）】**  
> 内側ループで選ばれたモデルはどちらも **78%〜85%という非常に高いスコア** を記録していましたが、完全に独立した外側テストセグメントで評価すると **決定木54.4%、RF 46.8%** に落ち着きました。  
> これにより、少人数・少数セグメント（N=23）のデータにおいて「最も良いモデルを選んでからテストする」従来手順がいかに過学習と過大評価を招いていたかが定量的に実証されました。

## スライド4：特徴量選択結果と安定性

### 23回の外側分割における特徴量選出率（全13特徴量）
23回のfoldごとに独立して行われた網羅探索において、どの特徴量が選抜されたかを全件比較。

| 特徴量名 | 決定木 (DT) 選出回数 | 決定木 選出率 (%) | RF 選出回数 | RF 選出率 (%) |
| :--- | :---: | :---: | :---: | :---: |
| **セグメント長 (`segment_length_sec`)** | **14 / 23** | **60.9%** | **21 / 23** | **91.3%** |
| **無音割合 (`pause_ratio`)** | **15 / 23** | **65.2%** | 0 / 23 | 0.0% |
| **感嘆符率 (`exclamation_ratio`)** | 3 / 23 | 13.0% | **12 / 23** | **52.2%** |
| **字幕-コメント類似度 (`sub_comment_similarity`)** | 9 / 23 | 39.1% | 2 / 23 | 8.7% |
| **発話速度 (`speech_rate`)** | 7 / 23 | 30.4% | 2 / 23 | 8.7% |
| **疑問符率 (`question_ratio`)** | 2 / 23 | 8.7% | 3 / 23 | 13.0% |
| **視線集中度平均 (`hm_mean`)** | 3 / 23 | 13.0% | 2 / 23 | 8.7% |
| **コメント密度 (`comment_rate`)** | 2 / 23 | 8.7% | 2 / 23 | 8.7% |
| **字幕感情極性 (`subtitle_sentiment_polarity`)** | 1 / 23 | 4.3% | 1 / 23 | 4.3% |
| **コメント分散 (`comment_semantic_variance`)** | 0 / 23 | 0.0% | 2 / 23 | 8.7% |

| **草コメント率 (`grass_ratio`)** | 0 / 23 | 0.0% | 0 / 23 | 0.0% |

### 特徴量選択の考察
1. **新特徴量 `segment_length_sec` の圧倒的な支配力**:
   - RFでは **91.3%（21/23回）**、決定木でも **60.9%（14/23回）** 選ばれ、両モデルともにセグメント長を最重要シグナルとして捉えています。
2. **モデルによる選好の違い**:
   - **決定木**: `pause_ratio`（無音割合: 65.2%）や `sub_comment_similarity`（類似度: 39.1%）との組み合わせを強く選好。
   - **Random Forest**: `exclamation_ratio`（感嘆符率: 52.2%）との組み合わせを強く選好。
3. **過去のRF+SFS結果（question_ratioが91%選出）との対比**:
   - 過去のSFS（逐次選択）では `question_ratio` が支配的でしたが、**網羅探索かつセグメント長を追加した本実験では DT: 8.7%, RF: 13.0% まで低下**しました。SFS特有の初期局所解から解放され、セグメント長と感嘆符率の組み合わせが優位と判定されたことがわかります。

## スライド5：考察と今後の課題

### 1. 実験結果の総括
- **分類性能の比較**:
  - 外側テストに対する Balanced Accuracy は **決定木 54.4% > Random Forest 46.8%** でした。
  - $N=23$ のような極小サンプルサイズでは、アンサンブル（RF）のバギング効果よりも、決定木のように明確なしきい値（セグメント長40秒、無音率など）でスパッと分けるシンプルなルールベースの方が外れ値に対する耐性が高い傾向が見られました。
- **解釈性と実用性**:
  - 決定木は「セグメント長が40秒未満かつ無音割合が低い場合は高満足度」といった具体的な配信改善ルールとしてそのまま提示できる点でも、研究成果としての有用性が高いと言えます。

### 2. 少数サンプル（N=23）による評価の限界
- 1サンプルの正誤で正解率が約 $4.3\%$ 変動するため、統計的な有意差を主張するには限界があります。
- 内側LOO-CVで $80\%$ を超えるスコアが出ているにもかかわらず、外側で $50\%$ 前後に落ちる現象は、**22件のデータでも過学習（楽観的適合）が発生している**ことを明確に物語っています。

### 3. 今後の課題・研究予定
1. **サンプルサイズの拡張**:
   - 配信アーカイブ動画の本数を増やし、セグメント数を $N=50〜100$ 規模に拡張して再検証。
2. **正則化の強化**:
   - 決定木の最大深さを $1〜2$ にさらに厳しく制限し、少数サンプル下での汎化性能の底上げを図る。
3. **マルチモーダル特徴量の結合方法の再検討**:
   - セグメント長に過剰に引っ張られないよう、特徴量の正規化や相互作用項の導入を検討する。
