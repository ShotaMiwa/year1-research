## スライド2：教授陣からの質疑への回答（決定木の非線形学習メカニズム）

### 質疑：「決定木は設定無しで非線形な特徴量を学習できるのですか？」
- **結論**: **はい、決定木はカーネル指定や特徴量エンジニアリング等の追加設定なしで、デフォルトのアルゴリズム構造そのものによって非線形な境界および条件付き相互作用を自動的に学習します。**

### 理論的メカニズムと本データにおける実事例
1. **軸平行分割の再帰的組み合わせによる非線形決定境界**:
   - 決定木の各ノードは局所的には線形な閾値判定（ \le \theta$）ですが、階層的に分岐が重なることで、特徴量空間を格子状に細分化し、**L字型・階段状の複雑な非線形境界**を形成します（線形分離不可能なXOR問題も深さ2で分離可能）。
2. **本データ（決定木 深さ2）で確認された条件付き相互作用の実例**:
   - question_ratio（疑問符率）が低い（$\le 0.202$）セグメントの中でのみ、第2階層の hm_mean（視線集中度）が有効な判定基準として機能し、高満足度と低満足度を綺麗に分岐。
   - 線形モデルでは交互作用項（ \times x_2$）を人手で設計しないと捉えられない関係を、決定木は構造的に自動獲得しています。

| モデル分類 | モデル名 | 非線形学習の可否 | 必要な前提・追加設定 |
| :--- | :--- | :---: | :--- |
| **線形モデル** | ロジスティック回帰 / 線形SVM | ✕ 不可 | 多項式特徴量や交互作用項の人手設計が必須 |
| **カーネル法** | 非線形SVM (RBF-SVM) | ◯ 可能 | カーネル関数指定（高次元空間への写像）が必要 |
| **木構造モデル** | **決定木 / ランダムフォレスト** | **◯ 可能** | **追加設定不要（区分定数近似・階層的分割により自動獲得）** |

## スライド3：実験設計（5大モデル選定理由とNested LOO-CVプロトコル）

### 比較対象の5大モデルと学術的選定理由

| モデル分類 | 対象モデル | 学術的役割・選定理由 |
| :--- | :--- | :--- |
| **線形モデル (1)** | **ロジスティック回帰 (LogReg L2)** | 特徴量の線形和のみでどこまで分離できるかの**線形ベースライン**。 |
| **線形モデル (2)** | **線形SVM (Linear SVM)** | 小標本データ（=23$）において過学習に強い**マージン最大化線形モデル**。 |
| **カーネル非線形** | **非線形SVM (RBF-SVM)** | RBFカーネルによる連続空間での**滑らかな非線形決定境界**の検証。 |
| **木構造・解釈性** | **決定木 (Decision Tree)** | 動画編集ルール（閾値判定）をIF-THEN形式で直接解釈できる**本研究の中核モデル**。 |
| **アンサンブル** | **ランダムフォレスト (Random Forest)** | 多数決により決定木のバリアンスを抑えた**高精度非線形アンサンブル**。 |

### 完全ダブルクロスバリデーション（Nested LOO-CV）の厳密設計
- **データ漏洩ゼロの標準化**: 線形モデルおよびSVMには、各Foldの**内側訓練データ（22件）のみに基づいて StandardScaler を適合**（テストデータへの情報漏洩ゼロ）。
- **網羅的特徴量探索**: 各Foldの内側ループで全78通り（ \in \{1, 2\}$）の全組み合わせを総当たり評価し、内側Balanced Accuracyが最大の特徴量セットを自動選出。
- **未知データの公平評価**: 選ばれたモデルを用いて、完全に隔離された外側の1件を予測。これを23回繰り返し外側総合性能を算出。

## スライド4：各モデルの二値分類メカニズムと出力形式の比較

### 本実験における二値分類の共通仕様
- **目的変数**: 10名の視聴満足度スコア（Target_Satisfaction）の中央値以上を **High (1)**、中央値未満を **Low (0)** と定義。
- **最終出力形式**: 全モデル一律で .predict() メソッドを使用し、**離散クラスラベル $\{0, 1\}$** を直接出力して評価（評価指標：Balanced Accuracy, F1-macro）。

### 各アルゴリズムがクラス判定を行う内部メカニズムの違い

| モデル分類 / モデル名 | 決定境界の形状 | 内部スコア / 決定関数 $f(x)$ | クラス判定ルール ($\hat{y}$) | 小標本 ($N=23$) での特徴 |
| :--- | :--- | :--- | :--- | :--- |
| **線形SVM (Linear SVM)** | 線形超平面（直線・平面） | 符号付き超平面距離: $f(x) = \mathbf{w}^T x + b$ | $\text{sign}(f(x)) \ge 0 \Rightarrow 1$ | **マージン最大化**により境界付近のノイズに最も頑健 |
| **ロジスティック回帰** | 線形超平面（直線・平面） | 事後確率: $P(y=1 \mid x) = \sigma(\mathbf{w}^T x + b)$ | $P(y=1 \mid x) \ge 0.5 \Rightarrow 1$ | 尤度最大化（確率推定）。外れ値・不均衡の影響を受けやすい |
| **決定木 (Decision Tree)** | 直交格子状の階段・L字境界 | 葉ノード内の多数派クラス | 葉の所属クラス $\Rightarrow \{0, 1\}$ | **解釈性最高**。局所ルールだが小標本では過学習リスク |
| **ランダムフォレスト** | 多数の直交境界の重なり | 決定木のアンサンブル多数決 | 投票割合 $\ge 0.5 \Rightarrow 1$ | 決定木のバリアンスを低減し安定化 |
| **非線形SVM (RBF)** | 連続的で複雑な曲面境界 | 無限次元カーネル超平面距離 | $\text{sign}(f(x)) \ge 0 \Rightarrow 1$ | $N=23$ ではパラメータ感度が高く**過学習を起こしやすい** |

### 線形SVMとロジスティック回帰の二値分類の違い（なぜSVMが勝ったのか）
1. **ロジスティック回帰（確率モデル）**:
   - 全データ点を使って対数尤度を最大化するよう重みを学習。境界から遠いサンプルの影響も受け、小標本では過学習・偏りが生じやすい。
2. **線形SVM（マージン最大化モデル）**:
   - 決定境界から最も近いサポートベクター（境界ギリギリの難解サンプル）との「マージン（余白）を最大化」することのみを目指す。
   - 境界から遠いサンプルの位置に左右されず、未知データに対する汎化マージンを物理的に確保できるため、**本検証のような小標本データで最高精度（65.1%）を発揮**。

   - サンプル数が23件と極めて少ない小標本環境では、RBFカーネルのように自由度が高すぎる連続非線形モデルは内側データに過剰適合し、外側の未知サンプルに対する汎化性能が大きく破綻することが判明。

## スライド6：特徴量選出の安定性とモデル別嗜好性の対比

### 学術的示唆：モデル構造による「特徴量嗜好性」の明確な二分化
1. **木構造モデル（RF / DT）における「セグメント長（動画の尺）」の絶対性**:
   - 決定木で100%（23/23回）、ランダムフォレストで95.7%（22/23回）選出。
   - 木構造モデルは「○秒以下なら切り捨て、それ以上なら盛り上がり判定」という**段階的・閾値的な非線形ルール**を形成するため、セグメント長が不可欠なアンカーとして機能している。
2. **線形モデル（Linear SVM / LogReg）における「連続テンポ指標」の重視**:
   - 線形モデルではセグメント長ではなく、question_ratio（疑問符率）や speech_rate（話速）といった**滑らかに増減するテンポ・対話指標**の線形和が好まれる。
   - **結論**: 「動画の尺による足切り」は木構造特有の非線形カットオフとして機能しており、モデルの性質によって捉えている視聴者心理の側面が異なることが判明。
