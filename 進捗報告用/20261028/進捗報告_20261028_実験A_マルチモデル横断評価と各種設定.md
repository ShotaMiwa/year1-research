## スライド2：教授陣からの質疑への回答（決定木の非線形学習メカニズム）

### 質疑：「決定木は設定無しで非線形な特徴量を学習できるのですか？」
- **結論**: **はい、決定木はカーネル指定や特徴量エンジニアリング等の追加設定なしで、デフォルトのアルゴリズム構造そのものによって非線形な境界および条件付き相互作用を自動的に学習します。**

### 理論的メカニズムと本データにおける実事例
1. **軸平行分割の再帰的組み合わせによる非線形決定境界**:
   - 決定木の各ノードは局所的には線形な閾値判定（ \le \theta$）ですが、階層的に分岐が重なることで、特徴量空間を格子状に細分化し、**L字型・階段状の複雑な非線形境界**を形成します（線形分離不可能なXOR問題も深さ2で分離可能）。
2. **本データ（決定木 深さ2）で確認された条件付き相互作用の実例**:
   - question_ratio（疑問符率）が低い（$\le 0.202$）セグメントの中でのみ、第2階層の hm_mean（視線集中度）が有効な判定基準として機能し、高満足度と低満足度を綺麗に分岐。
   - 線形モデルでは交互作用項（ \times x_2$）を人手で設計しないと捉えられない関係を、決定木は構造的に自動獲得しています。

| モデル分類 | モデル名 | 非線形学習の可否 | 必要な前提・追加設定 |
| :--- | :--- | :---: | :--- |
| **線形モデル** | ロジスティック回帰 / 線形SVM | ✕ 不可 | 多項式特徴量や交互作用項の人手設計が必須 |
| **カーネル法** | 非線形SVM (RBF-SVM) | ◯ 可能 | カーネル関数指定（高次元空間への写像）が必要 |
| **木構造モデル** | **決定木 / ランダムフォレスト** | **◯ 可能** | **追加設定不要（区分定数近似・階層的分割により自動獲得）** |

## スライド3：5大モデルの決定境界・式の形・分類メカニズムの直感的理解

### 1. 後輩・初学者でも一目でわかる「3つの決定境界グループ」

本研究で比較した5つのモデルは、データを分ける「境界線の引き方」によって大きく3つに分類されます。

```text
┌───────────────────────────┬───────────────────────────┬───────────────────────────┐
│ ① 線形モデル (直線で分ける) │ ② カーネル法 (曲面で分ける) │ ③ 木構造 (階段・L字で分ける)│
│    LogReg / 線形SVM       │    非線形SVM (RBF)        │    決定木 / ランダムフォレスト│
├───────────────────────────┼───────────────────────────┼───────────────────────────┤
│    y                      │    y                      │    y                      │
│    │     /  ○ (High)      │    │    ╭───╮  ○ (High)   │    │  ┌─────  ○ (High)    │
│    │    /                 │    │   │  ●  │            │    │  │                   │
│    │   /                  │    │    ╰───╯             │    └──┴─────              │
│    │  /   ● (Low)         │    │         ● (Low)      │       ● (Low)             │
│    └───                 x │    └───                 x │    └───                 x │
│  一次方程式でスッパリ切る │  曲面で島のように囲い込む │  「○秒以上」等で四角く切る│
└───────────────────────────┴───────────────────────────┴───────────────────────────┘
```

---

### 2. 各モデルが出力する「内部の式」と判定ルールの比較

「モデルは内部で何を出力しているのか？」を数式と判定ルールで整理しました。

| モデル分類 / モデル名 | 出力される式の形（決定関数） | クラス判定の仕組み（どうやって0/1を決めるか） | 直感的なイメージ・特徴 |
| :--- | :--- | :--- | :--- |
| **線形SVM (Linear SVM)** | $f(x) = w_1 x_1 + w_2 x_2 + b$ | $f(x) \ge 0 \Rightarrow 1$ (High)<br>$f(x) < 0 \Rightarrow 0$ (Low) | **【距離・マージン重視】**<br>境界線からの距離をスコアとし、符号（プラス/マイナス）で判定。境界ギリギリの難解サンプル（サポートベクター）だけを見るため小標本に強い。 |
| **ロジスティック回帰 (LogReg)** | $P(y=1 \mid x) = \frac{1}{1 + e^{-(w_1 x_1 + w_2 x_2 + b)}}$ | $P \ge 0.5 (50\%) \Rightarrow 1$<br>$P < 0.5 \Rightarrow 0$ | **【確率重視】**<br>一次式のスコアをシグモイド関数で「0%〜100%の確率」に変換して判定。全データ点を使って確率分布をフィッティングする。 |
| **カーネル非線形SVM (RBF-SVM)** | $f(x) = \sum_{i} \alpha_i y_i \exp(-\gamma \|x - x_i\|^2) + b$ | $f(x) \ge 0 \Rightarrow 1$ (High)<br>$f(x) < 0 \Rightarrow 0$ (Low) | **【無限次元写像・曲面境界】**<br>「RBF（ガウシアン）カーネル」という関数を使い、データを無限次元の高次元空間へ飛ばすことで、元の空間では複雑な曲面境界を描く。自由度が高すぎて小標本では過学習しやすい。 |
| **決定木 (Decision Tree)** | $\text{IF } x_1 \ge \theta_1 \text{ AND } x_2 < \theta_2 \dots$ | 最終的に到達した「葉（リーフ）」の所属クラス | **【ルール解釈性】**<br>「尺が60秒以上、かつ疑問符が0.2以下」のように人間がそのまま読める条件分岐ルールを出力する。 |
| **ランダムフォレスト (RF)** | $\text{Score} = \frac{1}{T} \sum_{t=1}^T \hat{y}_t$ (多数決) | 投票割合 $\ge 0.5 (50\%) \Rightarrow 1$ | **【アンサンブル・安定性】**<br>50本の決定木を作って多数決をとることで、1本の決定木のブレ（バリアンス）を抑えて安定化させる。 |

## スライド4：実験Aの設計方針と各種ハイパーパラメータ設定一覧

### 実験Aの学術的設計思想
- **目的**: 10/21の決定木（56.3%）およびランダムフォレスト（59.5%）と**完全に同一の基準・土俵**で他モデル（LogReg, 線形SVM, RBF-SVM）を公平に比較する。
- **小標本（$N=23$）に対する過学習抑止**: サンプル数が極めて少ない環境下でハイパーパラメータ探索を自由に行うと内側データへの過剰適合が起きるため、**「強い正則化・制約を事前設定した固定条件」**で比較を行う。

### 対象5大モデルと詳細設定一覧

| モデル分類 | 対象モデル (scikit-learn) | ハイパーパラメータ設定 | 標準化 (StandardScaler) | 選定理由・学術的役割 |
| :--- | :--- | :--- | :---: | :--- |
| **線形モデル (1)** | `LogisticRegression` | `penalty='l2'`<br>`C=1.0`<br>`solver='liblinear'`<br>`random_state=42` | **要 (内側適合)** | 全データを使って確率的決定境界を引く**線形ベースライン**。 |
| **線形モデル (2)** | `SVC(kernel='linear')` | `C=1.0`<br>`random_state=42` | **要 (内側適合)** | サポートベクターのみに着目し、小標本で堅牢な**マージン最大化線形モデル**。 |
| **カーネル非線形** | `SVC(kernel='rbf')` | `C=1.0`<br>`gamma='scale'`<br>`random_state=42` | **要 (内側適合)** | 無限次元カーネル写像により**滑らかな曲面決定境界**を形成する代表的非線形モデル。 |

### 特徴量プールの定義（全12種）
- **マルチモーダル特徴量プール**:
  1. **テキスト・対話（3種）**: `comment_rate`（コメント密度）, `question_ratio`（疑問符率）, `exclamation_ratio`（感嘆符率）
  2. **感情・心理（2種）**: `sentiment_polarity`（コメント感情極性）, `subtitle_sentiment_polarity`（字幕感情極性）
  3. **音声テンポ・熱量（2種）**: `speech_rate`（話速）, `grass_ratio`（草・笑い率）
  4. **視聴覚的注意（2種）**: `hm_mean`（視線集中度平均）, `hm_max`（視線集中度最大）
  5. **意味的多様性（2種）**: `comment_semantic_variance`（コメント意味分散）, `sub_comment_similarity`（字幕-コメント意味類似度）
  6. **新特徴量（1種）**: `segment_length_sec`（**セグメント時間長・動画の尺**）
- ※ 過去の予備実験で予測寄与が皆無であった「音響無音割合（silence_ratio）」は除外。

## スライド5：完全Nested LOO-CVのアルゴリズム詳細とデータ漏洩防止機構

### なぜNested LOO-CV（二重交差検証）が必要なのか
- 単純なLOO-CVの内部で全データを使って特徴量を選択すると、**テストデータに対する特徴量選択バイアス（データ漏洩・情報リーケージ）**が発生し、汎化性能を過大評価してしまいます。
- これを完全に防ぐため、**「外側23分割 × 内側22分割」の二重ループ構造**を採用しました。

```text
========================================================================================
【完全Nested LOO-CVの二重ループ実行フロー】
 全サンプル (N=23)
   │
   ├── [外側ループ: Fold 1 〜 23] ──────────────────────────────────────────────┐
   │     │                                                                       │
   │     ├─ 1件を完全に隔離 ───> 【外側テストデータ (1件)】 (未知サンプル)       │
   │     │                                                                       │
   │     └─ 残り22件 ──────────> 【内側学習データ (22件)】                       │
   │                                   │                                         │
   │           ┌───────────────────────┴─────────────────────────┐               │
   │           │ [内側ループ: 特徴量選択のためのLOO-CV (22分割)] │               │
   │           │  全78通り (k=1〜2) の特徴量セットを総当たり評価 │               │
   │           │                                                 │               │
   │           │  各内側Fold: 21件訓練 / 1件検証                 │               │
   │           │  ※ 線形/SVMは「21件のみ」からStandardScaler適合│               │
   │           │                                                 │               │
   │           │  内側Balanced Accuracyが最大の組み合わせを決定  │               │
   │           └───────────────────────┬─────────────────────────┘               │
   │                                   │ 最適特徴量セット (k*=1〜2)              │
   │                                   ▼                                         │
   │     【内側22件全体で最終学習】 ─────────────────────────────────────────────┤
   │       ※ 線形/SVMは22件でStandardScaler適合                                 │
   │                                   │                                         │
   │     【隔離された外側1件を予測】 <─┘                                         │
   │       ※ 外側1件は内側22件のScalerで変換して予測（テスト情報漏洩ゼロ）      │
   │       ※ .predict() による確定ラベル {0, 1} を記録                          │
   │                                                                             │
   └── 23回繰り返し、外側23件の予測結果を集約 ───────────────────────────────────┘
         │
         ▼
     【真の汎化性能の算出】 (Balanced Accuracy, F1-macro, 混同行列)
========================================================================================
```

### 厳密な実験条件のまとめ
1. **特徴量組み合わせ数**:
   - $k=1$（12通り）＋ $k=2$（66通り）＝ **合計78通りを内側ループで網羅的全探索**。

## スライド8：線形SVM・ロジスティック回帰の式の重み（係数）分析と定性的解釈

### 1. 23回の交差検証で実際に学習された「式の重み（係数）」ログ
「線形SVMやロジスティック回帰は、内部で具体的にどんな式を作っていたのか？」
