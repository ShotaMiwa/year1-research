## 1. 10/21進捗報告における教授陣からの質疑
> **質問**: 「決定木は設定無しで非線形な特徴量を学習できるのですか？」

---

## 2. 結論と理論的背景

### 結論
**はい、決定木は追加設定（カーネル変換や特徴量エンジニアリング等）なしで、デフォルトの構造自体によって非線形な関係および特徴量間の相互作用（掛け合わせ効果）を自動的に学習できます。**

### 理論的メカニズム：軸平行分割の再帰的適用
1. **局所的な線形分割と大域的な非線形性**:
   - 各決定ノード（分岐）は「$x_j \le \theta$」という**軸に平行な1本の閾値分割（局所的には線形）**を行います。
   - しかし、木が深くなるにつれて分岐が階層的に組み合わさることで、特徴量空間を格子状の小区画（hyper-rectangles）に細分化します。
   - これにより、全体として**階段状・矩形・L字型の複雑な非線形決定境界**を形成します。

```text
【XORパターンの非線形分割の例（線形分離不可能な問題）】
x1 <= 0.5 ?
├── True  -> x2 <= 0.5 ?
│             ├── True  -> クラスA (左下)
│             └── False -> クラスB (左上)
└── False -> x2 <= 0.5 ?
              ├── True  -> クラスB (右下)
              └── False -> クラスA (右上)
```
※ 直線1本（単一の線形境界）では絶対に分離できないXOR問題であっても、決定木は深さ2の構造だけで**追加設定なしに非線形な決定境界を構成し100%正解に分離可能**です。

### 線形モデル・他手法との対比
| モデル | 非線形の学習可否 | 必要な設定・操作 |
| :--- | :---: | :--- |
| **線形回帰 / ロジスティック回帰** | ✕ 不可 | 多項式特徴量（$x_1 \times x_2$等）や対数・二乗項の人手設計が必要 |
| **線形SVM** | ✕ 不可 | カーネル関数（RBFカーネル等）の指定が必要 |
| **決定木（Decision Tree）** | **◯ 可能** | **追加設定不要（モデル構造そのものが非線形・区分定数近似）** |
| **ニューラルネットワーク** | ◯ 可能 | 非線形活性化関数（ReLU, Sigmoid等）の導入が必要 |

## 3. 本研究（10/21実験）における実際の検証とログ

10/21に行った実験（Nested LOO-CVによる満足度高低の分類）において、**実際に決定木が非線形な決定境界および特徴量間の条件付き相互作用を学習した事例**が確認されています。

### ① 実際の決定木構造ログ

#### 事例A：深さ2（条件A：基本特徴量・セグメント長なし）
- **選抜特徴量**: `question_ratio`（疑問符率） × `hm_mean`（視線集中度・ヒートマップ平均）
- **学習された木構造**:
```text
[Node 0] question_ratio <= 0.202
├── True (疑問符率が低いセグメント: 19件)
│    └── [Node 1] hm_mean <= 0.061
│         ├── True (視線集中度も極めて低い: 2件)  -> Low Satisfaction (gini=0.0, 2/2件Low)
│         └── False (視線集中度は一定以上: 17件) -> High Satisfaction (gini=0.291, 14件High / 3件Low)
└── False (疑問符率が高いセグメント: 4件)
     └── (直ちに葉ノード)                         -> Low Satisfaction (gini=0.0, 4/4件Low)
```

#### 事例B：深さ3（条件D：セグメント長あり）
- **選抜特徴量**: `segment_length_sec`（動画長） × `question_ratio`（疑問符率）
- **学習された木構造**:
```text
[Node 0] segment_length_sec <= 40.0 秒
├── True (40秒以下の極短尺セグメント: 5件)
│    └── (直ちに葉ノード)                         -> Low Satisfaction (gini=0.0, 5/5件Low)
└── False (40秒より長いセグメント: 18件)
     └── [Node 1] question_ratio <= 0.202
          ├── True (疑問符率 <= 0.202: 16件)
          │    └── [Node 2] question_ratio <= 0.165
          │         ├── True  (<= 0.165: 10件) -> High Satisfaction (gini=0.0, 10/10件High)
          │         └── False (> 0.165: 6件)   -> High Satisfaction (gini=0.444, 4件High / 2件Low)
          └── False (疑問符率 > 0.202: 2件)
               └── (直ちに葉ノード)               -> Low Satisfaction (gini=0.0, 2/2件Low)
```

---

### ② 非線形・相互作用が実際に起きていた根拠（解釈）

1. **条件付き相互作用の獲得（特徴量間の掛け合わせ効果）**:
   - **事例A**: 「視線集中度（`hm_mean`）」は全体に一様に影響するのではなく、**「疑問符率が0.202以下」の領域においてのみ有効な判定基準として機能**しています。疑問符率が高い（>0.202）領域では、視線集中度の値にかかわらず即座にLowと判定されています。
   - **事例B**: 「疑問符率」による評価は、**「動画長が40秒超」という前提領域においてのみ**行われています。40秒以下の短尺セグメントではコメント内容は一切参照されずにLow判定されています。
   - 線形モデルであれば「$x_1 \times x_2$（交互作用項）」をあらかじめ手動で作らないと捉えられない関係ですが、決定木は**追加設定なしにこの非線形な条件付き関係を自動獲得**しています。

2. **L字型・逆L字型の決定境界（図による視覚的確認）**:
   - 決定境界プロット（下掲図）が示す通り、境界線は斜めの直線（線形境界）ではなく、**「垂直線と水平線が直交するL字型・階段状の境界」**となっています。
   - これが決定木による非線形学習の決定的な視覚的証拠です。

## 5. 補足：非線形性と過学習トレードオフ（深さ2 vs 深さ3）
- 決定木は設定なしで非線形性を捉えられる強力な表現力を持つ反面、**深さを大きくすると高次の非線形境界が過剰適合（過学習）を引き起こす**リスクがあります。
- 10/21の実験でも、深さ2（条件B）ではBalanced Accuracyが56.3%に向上したのに対し、深さ3（条件D）では51.2%へ低下しました。
- したがって教授陣に対しては、**「決定木は設定なしで非線形を学習できるが、小サンプル（N=23）では深さ（max_depth）等の制約によって非線形性の自由度をコントロールすることが重要である」**という点まで含めて回答するのが極めて説得力のある説明となります。
